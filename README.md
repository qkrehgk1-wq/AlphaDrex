# AlphaDrex

**현장 업무의 매뉴얼 확인부터 보고서 작성과 담당자 인계까지 연결하는 AI 에이전트**

AlphaDrex는 시설 점검과 교대 업무에서 필요한 매뉴얼 구절을 찾고, 확인된 사실을 보고 초안으로 정리해 담당자의 검토와 에이전트 수신함 전달까지 지원하는 Windows 단일 PC 시제품입니다. 라이너 .EXE-THON의 업무 문제 해결 과제로 개발했습니다.

## 해결하려는 업무 문제

현장에서 이상 징후를 발견하면 담당자는 적용할 매뉴얼을 찾고, 무엇을 확인했는지 기록하고, 다음 담당자에게 전달해야 합니다. 이 과정이 여러 문서와 대화에 나뉘면 근거가 빠지거나, 미확인 사항이 완료된 것으로 전달되거나, 인계 뒤 처리 상태를 알기 어려워집니다.

AlphaDrex는 이 반복 업무를 하나의 흐름으로 연결합니다. 매뉴얼에 담긴 확인 항목과 보고 절차를 답변의 근거로 사용하고, 사람이 검토한 문서 버전을 수신 에이전트에게 전달합니다.

## 실제 동작 흐름

1. **상황 입력** — 발생 시각, 구역, 시설 식별자와 관찰한 사실을 입력합니다.
2. **근거 확인** — 등록 매뉴얼에서 관련 구절과 문서명·행 번호를 확인합니다.
3. **보고 초안 작성** — Liner가 확인 목록과 보고 초안을 작성합니다. 미확인 항목을 함께 확인합니다.
4. **문서화와 검토** — 답변을 업무 문서로 저장하고, 확인한 사실·실제 수행한 조치·후속 요청을 검토합니다.
5. **담당자 인계** — 검토한 문서를 담당 에이전트 수신함에 등록하고 접수·회신 상태를 확인합니다.

최초 답변과 검토·후속 문서는 별도 기록으로 보존합니다. 정보가 부족하거나 문서가 충돌하면 추가 확인과 담당자 검토로 이어집니다.

## Liner를 핵심 기능에 사용하는 방법

| 기능 | Liner 활용 | 제품에서 확인할 결과 |
|---|---|---|
| 상황 판단과 근거 선택 | Model API에 상황과 외부 전송 승인된 매뉴얼 행을 전달 | 분류, 정보 부족·위험·검토 필요 판단, 선택한 근거 |
| 보고 초안 | Model API에 입력과 근거를 전달 | 한국어 확인 목록과 근거를 인용한 초안 |
| 최신 공개 정보 확인 | 사용자가 검색어를 확인하면 Search API 호출 | 검색 출처와 후속 검토 자료 |

아래 시연은 Model API의 판단과 초안 생성을 사용합니다. 공개 검색은 별도 기능이며 이번 영상의 호출 수는 0회입니다.

## 노하우를 다른 업무로 확장하기

업무 팩에 분류 기준, 추가 질문, 보고 서식과 매뉴얼을 등록하는 구조입니다. 시설 점검에서 시작해 교대 인계, 행사장 준비, 물품 대여·반납 등으로 업무 범위를 확장할 수 있습니다. 조직별 자료를 적용할 때는 문서 책임자가 최신판과 적용 범위, 외부 전송 허용 여부를 확인해야 합니다.

기대 효과는 담당자의 자료 탐색과 보고·인계 과정에서 반복 입력을 줄이는 것입니다. 실제 조직에서의 시간 절감과 기록 누락 감소는 시범 운영에서 측정할 과제입니다.

## 실행하기

Python 3.11 이상이 설치된 Windows PC에서 이 저장소를 내려받고 `start.bat`를 실행합니다. 브라우저에서 `http://127.0.0.1:8765`에 접속합니다. 기본 업무 팩에는 가상 매뉴얼 4개가 등록됩니다.

Liner 경로는 프로젝트 루트에 `env.local`을 만들고 다음 항목을 설정한 뒤 서버를 다시 시작합니다.

```dotenv
LINER_API_KEY=발급받은_키
LINER_MODEL=liner-gpt-router
ALPHADREX_BRAIN=liner
```

설정에서 **외부망**과 **외부 서비스 전송 허용**을 선택합니다. 질문을 보낼 때 **공개·가상 입력이며 외부 모델 전송을 확인했습니다**를 선택하면 Liner를 사용할 수 있습니다. API 호출에는 크레딧이 필요합니다.

기본값은 내부망이며 외부 호출을 서버에서 차단합니다. 내부망·외부망의 데이터는 각각 저장합니다. 설정에서 첫 관리자를 생성하면 로그인과 관리자·근무자 권한이 적용됩니다.

## 기술 구성과 확인 범위

- Python 표준 라이브러리 기반 HTTP 서버, SQLite, HTML·CSS·JavaScript 화면
- Liner Model·Search API를 사용하는 중앙 제공자 어댑터
- 로컬 Drex를 선택할 수 있는 판단 경로
- 문서 버전·검토 기록, 에이전트 인증과 수신함 API
- TXT·MD·HWPX 문서 등록, `pypdf` 설치 시 텍스트 PDF 등록

이 저장소에 포함한 전송 처리 회귀검사 3건은 다음 명령으로 실행할 수 있습니다.

```powershell
python -m unittest discover -s tests
```

단일 PC의 가상 자료 시범 환경에서 검증했습니다. 기관 적용에는 전문가의 근거 검토, 문서별 접근 통제, 개인정보·보안 정책과 장기 운영 검증이 필요합니다. 긴급 상황에서는 소속 기관의 긴급 절차와 현장 지휘 체계를 우선합니다. 로컬 Drex의 CPU 응답 지연은 개발 환경에서 확인된 제한입니다.
